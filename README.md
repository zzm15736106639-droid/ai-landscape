# AI Landscape

AI Landscape is a Windows desktop tool that converts portrait videos to
`1280x720` landscape videos. It splits the source into shots, samples one frame
per second for OpenCV YuNet face detection, chooses a fixed crop for each shot,
and switches crops on exact decoded frame indexes.

The output timeline is unchanged. The application does not trim, accelerate,
loop, blur, or randomly discard output frames.

## Features

- Face-aware 16:9 reframing with eye-centered handling for oversized faces
- Editable per-video upper and lower crop limits
- Exact frame-index shot switching with balanced FFmpeg expressions
- Multiple videos and independent work windows
- Transparent GIF, MOV and WebM effect library with fixed and balanced-random modes
- SRT filename matching, text overrides, layout, font, outline and shadow editing
- FFmpeg/libass subtitle truth preview
- Serial AI analysis followed by 1-8 concurrent encodes
- CPU or NVIDIA NVENC H.264 encoding, progress, cancellation and performance logs

## Requirements

- Windows 10/11 x64
- Python 3.10 or newer
- Node.js 20 or newer
- PowerShell 5.1 or newer

YuNet runs on CPU. The GPU option controls FFmpeg encoding only.

## Development

```powershell
git clone https://github.com/zzm15736106639-droid/ai-landscape.git
cd ai-landscape
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
.\scripts\fetch_third_party.ps1
npm.cmd --prefix frontend ci
npm.cmd --prefix frontend run build
python app.py
```

Open http://127.0.0.1:5688. For Electron development, set the Python path when
needed and run:

```powershell
$env:AI_LANDSCAPE_PYTHON = "$PWD\.venv\Scripts\python.exe"
npm.cmd install
npm.cmd run desktop:dev
```

## Verification

```powershell
python -m pytest
python scripts\verify_resources.py
npm.cmd --prefix frontend run lint
npm.cmd --prefix frontend run build
npm.cmd run desktop:check
```

Run the complete API, YuNet analysis and encoding path with a local portrait
video:

```powershell
python scripts\smoke_test.py D:\path\to\portrait-video.mp4
```

Smoke-test outputs are written to `.test-output` and are ignored by Git.

## Windows Packaging

```powershell
pip install -r requirements-dev.txt
.\scripts\fetch_third_party.ps1
npm.cmd install
npm.cmd --prefix frontend ci
npm.cmd run dist:win
```

Installers are written to `dist-desktop`. Release builds also attach the
corresponding FFmpeg source archive generated by
`scripts/fetch_release_sources.ps1`.

## Runtime Data

Effects, imported subtitles, analysis caches and performance logs are stored
under the Electron user data directory. No effect media ships in the source
repository.
