# Contributing

1. Create a focused branch from `main`.
2. Keep AI analysis and rendering changes covered by tests.
3. Run the commands in the README verification section.
4. Do not commit media samples, downloaded fonts, FFmpeg binaries, caches or logs.
5. Preserve exact frame-index crop switching and the unchanged source timeline.

Bug reports should include the application version, FFmpeg version, relevant
error text and a redacted `detect.json` when possible. Do not upload private
videos without permission.
